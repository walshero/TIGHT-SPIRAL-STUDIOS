# SPOOL — convening findings (2026-11-07)

Founder sentence (2026-11-07, verbatim): "A game like candy crush meets Tetris and it teaches you about epigenetic expression through DNA"

Working title: **Spool** (DNA winds on histone spools; the studio name is a tight spiral). PENDING R1.

## What the player does
Steer falling three-letter strand pieces (Tetris), then swap settled letters to make runs of three (Candy Crush). A run is a READ; reads build a protein chain. Marks block reads without changing a single letter.

## What Matt wants them to notice
The letters never change. Gray caps (DNA methylation) and tight spools (deacetylated histones) decide what the cell can read. Same strand, different marks, different expression.

## Seats
- **Horvath (learning science):** one concept per level, in order: read → cap → spool → signals. The letter stays visible under the cap; that visual carries the claim "sequence unchanged". Retrieval comes from use: the eraser and key are verbs, not glossary entries.

## Science (research first; sources)
- Epigenetics: heritable changes in gene expression without a change in DNA sequence (NHGRI glossary, via IEEE TechNav summary).
- Methylated CpG islands stop transcription; histone acetylation loosens nucleosome packing so transcription factors can bind (ASHG Discover Genetics fact sheet, 2024).
- DNMTs write methyl marks; HATs add acetyl; hypermethylation represses, acetylation activates (PMC8611190 table 1). TET enzymes start active demethylation; HDACs remove acetyl.

**Studio inventions (labeled in the game's Notes):** falling pieces, swapping, the eraser and key as pieces, rows as spools, reads as runs of three, signals on a timer.
