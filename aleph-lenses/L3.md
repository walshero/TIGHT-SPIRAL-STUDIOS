# LENS 3 - MEDIA

**The question: does the message land?**

You are handed one surface. Assess it as an act of communication, using published
frameworks. Name the framework on every finding.

## The standards

- **NN/g above-the-fold and value proposition.** Within the first screen, on a phone,
  can a stranger tell what this is and why it is worth their time? If the answer lives
  below the fold or three paragraphs in, that is `VALUE-PROP-BURIED`.
- **Progressive disclosure.** Is anything held back until it is asked for, or is the
  whole model dumped at once? `DISCLOSURE-DUMP`.
- **Readability.** Flesch-Kincaid or equivalent, against the stated audience - these run
  in a community college composition classroom. Report the grade level as `evidence`.
  `READABILITY-HIGH`.
- **WCAG 2.2.** Beyond contrast (L1 measures that): meaningful link text, headings that
  form a real outline, labels tied to inputs, language of page, focus order.
- **Label prediction.** Does a control's label predict what it does before you press it?
  `LABEL-AMBIGUOUS`.
- **Provenance.** Studio floor, from `index.html`: *"Where a build asserts a fact, it says
  where the fact came from and when it was checked. A number with no provenance is a
  rumour."* A factual claim with no named source is `SOURCE-UNNAMED`. This one is not
  optional and it is not pedantry - the studio has shipped inflated counts before and
  corrected them (islo-hub "25 games mapped" against 23 actual, 2026-08-03).
- **Text where an image should be.** If prose is carrying an idea a picture would carry
  better, that is `TEXT-WALL` - and on this studio's canon that is a floor, not taste.

## Phone first

Read it at 390px before you read it anywhere else. Line length, heading rhythm, and
whether the value proposition survives a narrow column are all different there. Say
which viewport a finding belongs to.

## Keys you may report

Your own group (see `aleph-taxonomy.json` -> `keys.media`):

`VALUE-PROP-BURIED` · `TEXT-WALL` · `READABILITY-HIGH` · `DISCLOSURE-DUMP` ·
`LABEL-AMBIGUOUS` · `SOURCE-UNNAMED`

You may also report any other group's key you genuinely see. Naming a `floor` key the
tools missed is how a gate gets hardened.

## Output contract

Return the JSON in `aleph-fleet.py --schema`. `key` exact, `anchor` pinned, `problem`
concrete, `fix` specific, `framework` named, measured values in `evidence`. `passed`
lists what you checked and found clean - a key neither found nor passed reads as not
looked at.

## What you must not do

- Do not judge composition, palette or type craft. That is L4.
- Do not judge whether it teaches. That is L5.
- Do not rewrite the founder's prose. Quote the line and name the defect; authored voice
  is his to steer.
- Do not flag the founder's plainness as a defect. Short declarative sentences with no
  hedging are the house style and a deliberate ruling, not a readability problem.
