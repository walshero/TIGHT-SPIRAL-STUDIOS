## OPENING THE LANE PERMANENTLY (founder action, one time)

The fetch lane from Claude Code sessions is governed by this environment's
network policy (docs: code.claude.com/docs/en/claude-code-on-the-web). To open
it: claude.ai → Claude Code → your environment's settings → network access →
add these domains (or choose the policy tier that includes them):

```
loc.gov
www.loc.gov
tile.loc.gov
commons.wikimedia.org
upload.wikimedia.org
archives.gov
catalog.archives.gov
www.jfklibrary.org
```

Until that lands, sessions here can RESEARCH (server-side WebSearch works —
proven 2026-08-08) but not fetch. Rows below stay TO-VERIFY until a session can
open each item's own rights page.

## THE PIPELINE (each row moves left to right, never skipping)

FOUND (search) → TO-VERIFY (open the item's rights page; record the license
string verbatim + the source URL) → VERIFIED → DOWNLOADED (staged in
`cyl-assets/` with `provenance.json` beside it) → MOUNTED (composited per the
period bible; provenance data-art string in the HTML; belt-gated).

## FLOORS (inherited, non-negotiable)

- PD-first: LOC "no known restrictions" · National Archives / US-gov · Commons
  PD/CC0. License string recorded verbatim in provenance.
- **No real leader faces in CYL, ever** — the room is the subject; the figure is
  withheld (period bible law). A photo whose TV screen resolves a president's
  face is reference-only, never a mount, unless the screen is cropped/blurred to
  scan-line texture per the bible.
- No baked game text; period print as texture only.
- Class representation is a sourcing requirement, not a garnish: every era needs
  more than the suburban living room (founder's v7 order — different class
  positions, different media apertures).
